# Validation data

## `janaf_reference.csv` (Milestone 1)

Generated by `scripts/fetch_thermo_data.py` from the NIST-JANAF tables listed in
`data/SOURCES.md`. Do not edit by hand; rerun the script.

Columns (one row per species and temperature, units in the header name):

```
species,T_K,Cp_J_molK,S_J_molK,H_minus_H298_kJ_mol,dfG_kJ_mol,source
```

- `species` matches a key in `data/species.yaml`.
- `H_minus_H298_kJ_mol` is the JANAF column "H-H°(Tr)"; `dfG_kJ_mol` is "delta-f G°".
  dfG is used to check equilibrium constants by an independent route:
  delta_r G = sum(nu * dfG).
- Rows are only included where the species' Shomate data cover the temperature
  (H2O starts at 500 K).
- Fe0.947O rows come from the same JANAF table its Shomate fit was made from, so for that
  species the Cp/S/H comparison measures fit quality, not independent agreement.

## `reference_model_marsigny2025b_caseA.csv` (Milestone 5)

Case A outputs of REDUCTOR (Marsigny, Mirgaux & Patisson 2025, Metals 15:862, Table 1),
written by `scripts/extract_reductor_table1.py`. Columns `key,unit,value,printed,output,
description`; units as printed (degC, %, t/h, GJ/t, Pa). `output = 1` marks values printed
in bold (model outputs). Read from the page image; every value is checked against the PDF
text layer, and the script checks that the DRI composition gives the reported metallisation.

## `reference_model_marsigny2025b_caseA_profiles.csv` (Milestone 5)

Cross-section averages of the case A maps (Figs. 3, 4, 6-9), written by
`scripts/digitize_reductor_maps.py`, every 0.1 m from z = 14.9 to -9.8 m (z = height above
the bottom of the upper cylinder; bustle 4.9 m). Columns: `quantity` (T_solid degC, x_H2,
w_Fe2O3, w_Fe3O4, w_FeO, w_Fe), `mean` (area-weighted average of the colour-band
midpoints), `mean_lo`/`mean_hi` (the same with the band edges: the true average lies in
between), `centre`/`wall` (r < 0.15 m / outer 0.15 m), `r_edge` (detected radius of the
coloured region, checked against the geometry), `classified` (fraction of pixels matched to
a band). Resolution: one colour band (100 K, 0.05 in H2 fraction, 0.1 in mass fraction).
